## What counts as a real accomplishment

Do **not** conflate these distinct gates:

- **Implemented:** source code or useful templates exist at a referenceable revision.
- **Technically verified:** an identified test actually ran against an identified version/platform; source-free fixtures prove only the tested behavior.
- **Integrated:** the exact version is merged into the intended runtime branch. Draft / stacked PRs are *not* integrated into main.
- **Rendered/deployed:** a specific complete real input produced an inspectable video/site/report on its actual target host and output destination.
- **Accepted:** Amar or an authorized client viewed the **exact artifact version** and explicitly approved the result.
- **Delivered/paid:** evidence establishes authorized release/handoff, and separate payment confirmation if money is claimed.

A component can pass 100+ tests while **not** passing integrated, rendered, accepted, or delivered. A green GitHub-hosted Windows check cannot demonstrate Evan's actual laptop, and a working original rig compiler cannot demonstrate a running Moho ghost employee. Do not imply unsourced dollar revenue, customers, prospects, testimonials, rankings or time saved.
