## Private acceptance manifest — required fields, no media in GitHub

A future **authorized private** editor session creates one manifest per review revision. Do **not** commit original audio, art, captions/transcripts, absolute user paths, client identifiers, private project titles, or derived media hashes to this public repository. Public evidence may reference an opaque review ID and state that private receipts exist; only a permitted reviewer may inspect them.

| Field (private manifest) | Acceptance rule / evidence |
| --- | --- |
| `review_id`, `source_revision`, `editor_revision`, `created_utc` | Stable revision identity and exact editor/adapter version. Changing source, crop, caption or mix starts a new review revision. |
| `narration.original_sha256`, `narration.duration_samples`, `narration.sample_rate` | Computed from the **actual** original recording in private storage, not a fabricated value. Preserve original bytes and source-derived PCM mapping. |
| `art_assets[]` (`asset_id`, `source_sha256`, `approved_revision`) | Every visible Evan/prop/background asset traces to an actual reviewed source file; no stand-in illustration or silent asset replacement. |
| `timeline.source_start_frame`, `timeline.source_end_frame_exclusive`, `timeline.fps_num=60`, `fps_den=1` | Whole-source frame coordinate mapping; all used segments continuous where required; no dropped/repeated frames at joins. |
| `captions[]` (`cue_id`, `start_frame`, `end_frame_exclusive`, `reviewed_text_revision`, `source_word_ids[]`) | Each cue has positive duration, stays within timeline, is ordered, matches the *heard* words, and maps to the reviewed audio alignment. Store actual text only privately. |
| `landscape` and `portrait` (`project_id`, `export_id`, `width`, `height`, `fps`, `decoded_frames`, `decoded_duration`, `audio_track`, `caption_mode`, `receipt_id`) | **Independent** evidence for 1920×1080 and 1080×1920 at exactly 60/1 fps; decoded media, not just project settings or filename. |
| `library_proof` (`isolated_library_id`, `selected_in_app`, `observed_project_id`, `evidence_method`) | Must prove **which isolated library is actually selected** before native import is separately authorized. A directory existing on disk or a successful Apple event is insufficient. |
| `review_samples[]` (`format`, `start_frame`, `end_frame_exclusive`, `sample_receipt_id`, `human_decision`) | At least one **independent 30-second-or-longer** decoded sample **per format**; 1,800 frames minimum at 60 fps. Distinct framing reviews, not the same landscape crop asserted as portrait proof. |
| `checks[]`, `blockers[]`, `owner_signoff` | Per-check pass/fail/untested with private evidence pointer; record all untested operations; owner visual approval is a separate explicit event, never inferred from CI. |

Use `unknown`/`not_run` for missing evidence; do **not** invent sample IDs, durations, model activity, file hashes, library selection, or signoff. A hash by itself proves identity only if independently recomputed from the authorized actual file.

## Review gates and failure handling

| Gate | How a future authorized operator verifies it | Reject / rollback condition |
| --- | --- | --- |
| 0. Identity & isolation | Record original narration/art file digests in private receipts; confirm **new disposable** FCP library and selected-library evidence before any write. | Any pre-existing Untitled/production library is selected, selected-library proof is missing, or source identity changes unexpectedly: **stop**; never replay a failed native attempt under a new ID. |
| 1. Audio integrity | Compare output narration at beginning, middle, chapter seams and end to the original decoded PCM reference using a documented offset/alignment method; inspect duration and any unexpected speed/stretch. Music/SFX must not mask spoken words. | Missing/repeated words, resampling/speed changes without authorization, seam drift, narration encoded independently in each chapter, or no original source reference: fail. |
| 2. Video technical | Decode **both** exports independently. Check 1920×1080 vs 1080×1920, exact 60/1 frame rate, monotonic timestamps, actual frame count and audio presence. For a 30s sample, require at least 1,800 decoded frames; compare expected count to sample span and container duration. | Wrong orientation, stretched portrait, incorrect fps, missing audio, corrupted decode, black/missing frames, discontinuity or shorter-than-required review sample: fail. |
| 3. Caption/acoustic | Review cue start/end against actual audible English, including reductions and challenging words; inspect both orientations for clipping and safe margins. Capture timing error at the 60fps frame grid and flag any cue off by more than one frame for manual correction (not automatic approval). | Captions derived only from spelling or an unreviewed forced aligner, cues crossing cuts incorrectly, truncated words, overlaps that hide text, unreadable/occluded captions: fail. |
| 4. Art, motion & crop | Inspect the original approved Evan face/rig and prop identity, lip contacts, wrist-to-prop/surface contact, background continuity, and distinct 16:9/9:16 blocking at normal speed. | Slideshow/still substitutions, invented source art, cropped face/prop, broken physical contact, visual defects, or changed approved identity: fail pending creative repair. |
| 5. Human decision | Owner reviews one independently decoded ≥30s landscape sample and one ≥30s portrait sample, plus any flagged audio/caption seam; record `pass`/`fail` separately for each and for the whole cut. | Missing review, review on stale revision, or any explicit fail: remain `needs_review`, **not** publishable. |
| 6. Recovery | Retain original input, prior successful review exports, and immutable failed attempt receipt; undo only **disposable** project changes with owner permission. | Never delete/rename an existing FCP library, retry a partially completed GUI action blindly, enable legacy import, or promote a failed draft to done. |

**Proposed private command evidence, not executed here:** an authorized host could record `ffprobe -v error -show_streams -show_format -of json <private-export>` and a decoded-frame check using trusted local tooling. The operator must log exact command, tool version, input/output identities, exit status and observed result **privately**. Container metadata alone does not prove caption accuracy, acoustic sync, native app selection or visual quality.

## Explicit unknowns and approval boundary

1. **Unverified on the actual Mac:** creation and selection of a truly isolated FCP library; import into that selected library; timeline inspection; captions applied; both 60fps exports; decoded audio sync; editor project recovery. Existing GitHub CI cannot settle any of these.
2. **Unverified for real sources:** original approved asset digests, original narration duration and rights, accurate English acoustic alignment, frame-perfect source/chapter seams, safe caption placement, music/SFX rights and final visual approval. No private sources were read.
3. **Next read-only owner-approved gate:** collect a **sanitized** current native library-selection status/receipt from the authorized Mac (no GUI writes) and confirm that a *new disposable* library, not the existing Untitled library, is actually selected. If that proof is absent, do not authorize import, edit or export. The private reviewer then fills the manifest with actual assets and tests one separately approved synthetic project before any real-media trial.

**State transition:** `research_contract_drafted` → `private_inputs_verified` → `isolated_library_selected_verified` → `synthetic_edit_export_verified` → `real_source_dual_format_technical_pass` → `owner_visual_pass`. Each arrow needs a new recorded proof and applicable approval. This GitHub document reaches only the **first** state.
