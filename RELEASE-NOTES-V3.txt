ROVOR DIGITAL VIDEO ENGINE V3.2.0 — OCTOBER 19 2026

CAPTION REVIEW AND RENDER SAFETY:
- Each render now writes an editable captions.srt for correcting transcript text and timing.
- Caption-only revisions reuse saved Whisper and Rhubarb results instead of repeating those slower stages.
- Caption changes invalidate cached frames and trigger a new MP4 encode; the previous MP4 stays available until replacement.
- Render progress is checkpointed, incomplete frames are regenerated, and concurrent processes cannot write to one render folder.
- Both character styles now render the edited SRT captions while keeping legacy scene files readable.

PORTABILITY AND RENDER RELIABILITY:

IMPLEMENTED IN THIS UPDATE:
- Windows and macOS launchers share validated local-tool configuration.
- A Windows PowerShell setup script prepares Sharp and adds the MCP adapter without overwriting an existing config or MCP entry.
- Windows paths with spaces are supported by the interactive launcher.
- Resume checks fingerprint audio, manual scene plans, tool configuration, and resolved tool/model file metadata.
- Resume checks include the engine version so newer rendering code cannot silently reuse old frames.
- Saved render metadata is written atomically; malformed transcript and lip-sync outputs are rejected.
- Empty audio is rejected before transcription; malformed timing values are filtered out.
- WAV conversion is validated and replaced atomically; long recordings stop converting shortly after the supported limit.
- Long captions are wrapped and bounded to the on-screen caption area in both character styles.
- Reference frames use one Sharp compositing pipeline, avoiding an extra full-frame encode/decode.
- Frame batch ranges and saved scene plans are validated before rendering.
- Render and MCP process handling now accounts for Windows process semantics.
- Sharp is pinned in package.json for repeatable setup on supported Node versions.
- Engine and MCP versions are aligned at 3.2.0.

VALIDATION:
- The existing test suite and a full Windows render were not run for this update.
